# macOS 27のfmとは？ターミナルからAppleのAIを使う方法

MacでAIを使うと聞くと、専用のアプリやWebサイトを開き、質問を入力する場面を思い浮かべるかもしれません。

macOS 27には、AppleのAIを利用するためのコマンド「fm」が標準搭載されました。Macの「ターミナル」というアプリで質問や指示を入力すると、AIから回答を受け取れます。[Appleの公式紹介](https://developer.apple.com/videos/play/wwdc2026/334/)

この記事では、プログラミングに詳しくない人に向けて、fmの役割と使い方を紹介します。2026年10月6日時点の公式資料をもとにした内容で、実機での動作や日本語の回答品質はまだ確認していません。

## fmとは？

fmは、Apple Foundation Modelsをターミナルから利用するためのコマンドです。Apple Foundation Modelsは、文章の理解や回答の生成などを行うAIモデルです。ここでいう「AIモデル」とは、入力された内容をもとに回答を作る仕組みを指します。

Appleは、アプリの開発者向けに「Foundation Modelsフレームワーク」も提供しています。これは、AIの機能をアプリに組み込むための開発用の仕組みです。[Foundation Modelsの公式資料](https://developer.apple.com/documentation/FoundationModels)

## ターミナルとは？

ターミナルは、文字を入力してMacに指示するアプリです。

普段はボタンやメニューをクリックして操作しますが、ターミナルでは「コマンド」と呼ばれる指示を入力します。fmも、そのコマンドの一つです。

見慣れない画面に戸惑うかもしれませんが、fmで質問するには、次に紹介するような一行のコマンドを入力するだけです。

## まずは一つ、質問してみる

macOS 27のMacでターミナルを開き、次の一行を入力してReturnキーを押します。

```sh
fm respond 'AIとは何か、専門用語を使わずに3文で説明して'
```

`fm respond`は、AIに質問や指示を送り、回答を受け取るコマンドです。その後ろの半角のシングルクォート `'` で囲んだ部分に、質問や指示の内容を書きます。

文章を囲む引用符には、シングルクォートを使ってください。Macの標準的なターミナル環境では、ダブルクォート `"` の内側に `$()` やバッククォートで囲まれた部分があると、その部分がコマンドとして実行されます。シングルクォートで囲むと、コマンドとして実行せず、文章としてAIに渡せます。

ただし、本文に半角のシングルクォート `'` があると、そこで文章の区切りと解釈されてしまいます。本文に含まれる `'` は、一つずつ `'\''` に置き換えてください。例えば、`It's` を含む文章は次のように書きます。

```sh
fm respond '次の文を日本語に訳して：It'\''s a sunny day.'
```

この書き方では、文章の区切りをいったん閉じ、シングルクォートを文字として渡してから、続きを記述します。長い文章やコードを貼り付ける際も、本文に `'` が含まれていないか確認してください。

上のコマンドにある質問文は、この記事で用意した例です。実際の回答はまだ確認していません。

続けて会話したいときには、次のコマンドを使います。

```sh
fm chat
```

`fm chat`を使うと、最初の回答に対して追加の質問をするなど、会話を続けられます。[基本操作の公式解説](https://developer.apple.com/videos/play/wwdc2026/334/)

## どんなことに使える？

Foundation Modelsは、文章の要約や書き直し、必要な情報の取り出しなどに使えると案内されています。[Foundation Modelsの公式資料](https://developer.apple.com/documentation/FoundationModels)

例えば、次のような用途が考えられます。

- 自分で書いた説明文を、短く分かりやすくする
- メモから、やることを箇条書きにする
- 難しい言葉を、身近な例に置き換えて説明してもらう

自分の文章で試すときは、「次の文章を短くして」といった指示に続けて、対象の文章も入力します。文章を渡す際は、先ほどの引用符の注意点も確認してください。「メモを整理して」と入力するだけでは、Macに保存したメモは読み取られません。

## Macの中で動くAIと、サーバーで動くAI

fmは、初期設定ではMacの中で動くAIモデルを使います。このように、手元の機器で処理する方式を「オンデバイス」と呼びます。

Appleの「Private Cloud Compute」で動く、より大きなAIモデルに切り替えることもできます。こちらはAppleが用意したサーバーで処理する方式で、利用制限があります。[モデルの違いについての公式説明](https://developer.apple.com/videos/play/wwdc2026/334/)

fmで使うモデルによって、処理する場所が変わります。

AppleのAIモデルを使うには、Apple Intelligenceに対応したMacが必要です。利用する前に、自分のMacが対応しているか確認してください。[Foundation Modelsの利用条件](https://developer.apple.com/documentation/FoundationModels)

## 作業の自動化にもつながる

fmは、繰り返し行う作業を自動化するためにも使えます。

Appleは、ファイル名の一覧をAIに渡し、「最終版」と「下書き」に分類する例を紹介しています。分類結果をもとに、最終版をバックアップ先へコピーし、下書きを保管先へ移動します。[Appleのファイル整理デモ](https://developer.apple.com/videos/play/wwdc2026/334/)

この例では、AIがファイル名から分類を判断します。コピーや移動は、あらかじめ用意したプログラムが行います。こうしたプログラムを「スクリプト」と呼びます。ファイル整理を自動化するには、fmに加えて、整理の手順を記述したスクリプトが必要です。

スクリプトの作成には知識が必要ですが、このようにfmを使うと、作業の一部をAIに判断させることができます。

## 最初は短い文章で試してみる

初めて使うなら、自分で書いた短い文章を、分かりやすく書き直してもらうところから試すとよさそうです。元の文章と回答を見比べれば、どこが変わったかを確認できます。

日本語でどのくらい自然に答えられるか、どのような作業が得意かは、実際に試して確かめたいところです。

まずは短い質問や文章を入力し、どのような回答が返ってくるか確認してみてください。
