# macOS 27のfmとは？MacのAIに文字でお願いできる新しい道具

MacでAIを使うと聞くと、専用のアプリやWebサイトを開き、質問を入力する場面を思い浮かべるかもしれません。

macOS 27には、もう一つの入口として「fm」という道具が標準搭載されました。Macの「ターミナル」というアプリから、AppleのAIに文章でお願いできます。[Appleの公式紹介](https://developer.apple.com/videos/play/wwdc2026/334/)

この記事では、プログラミングに詳しくない人に向けて、fmの役割と使い方を紹介します。2026年10月6日時点の公式資料をもとにした内容で、実機での動作や日本語の回答品質はまだ確認していません。

## fmは、AIへお願いするための入口

fmは、Apple Foundation Modelsを使うための道具です。Foundation Modelsは、文章を理解したり、回答を作ったりするAIモデルのこと。AIモデルは、入力された内容をもとに答えを作る仕組みだと考えると分かりやすいでしょう。

Appleは、この仕組みをアプリに組み込むためのFoundation Modelsフレームワークも提供しています。「フレームワーク」は、開発者が機能を使うための共通の部品です。[Foundation Modelsの公式資料](https://developer.apple.com/documentation/FoundationModels)

fmでは、そのAIへターミナルから直接お願いできます。

## ターミナルとは？

ターミナルは、文字を入力してMacに指示するアプリです。

普段はボタンやメニューをクリックして操作しますが、ターミナルでは「コマンド」と呼ばれる指示を入力します。fmも、そのコマンドの一つです。

画面に見慣れない文字が並ぶため難しそうに感じるかもしれませんが、最初の質問には長いプログラムを書く必要はありません。

## まずは一つ、質問してみる

macOS 27のMacでターミナルを開き、次の一行を入力してReturnキーを押す、というのが基本の使い方です。

```sh
fm respond 'AIとは何か、専門用語を使わずに3文で説明して'
```

`fm respond`は「AIにお願いして、回答を受け取る」という指示です。その後ろの半角のシングルクォート `'` で囲んだ部分に、お願いしたい内容を書きます。

ここでは、引用符の種類にも意味があります。Macの標準的なターミナル環境では、ダブルクォート `"` の内側に `$()` やバッククォートがあると、その部分を別のコマンドとして実行してしまいます。シングルクォートで囲むと、これらを文章のまま渡せます。

ただし、本文に半角のシングルクォート `'` がある場合、そのまま貼り付けると囲みが途切れます。その文字は、一つずつ `'\''` に置き換える必要があります。例えば、`It's` を含む文章は次のように書きます。

```sh
fm respond '次の文を日本語に訳して：It'\''s a sunny day.'
```

これは、いったん囲みを閉じ、シングルクォートそのものを渡して、再び囲みを開く書き方です。長い文章やコードを貼り付ける際も、本文にこの文字が含まれていないか確認してください。

この質問文は、この記事で用意した例です。実際にどのような回答になるかは未確認です。

続けて会話したいときには、次のコマンドを使います。

```sh
fm chat
```

こちらは対話用の入口です。最初の質問のあとに、追加の質問をして会話を続けられます。[基本操作の公式解説](https://developer.apple.com/videos/play/wwdc2026/334/)

## どんなことに使える？

Foundation Modelsは、文章の要約や書き直し、必要な情報の取り出しなどに使えると案内されています。[Foundation Modelsの公式資料](https://developer.apple.com/documentation/FoundationModels)

例えば、次のような頼み方が考えられます。

- 自分で書いた説明文を、短く分かりやすくする
- メモから、やることを箇条書きにする
- 難しい言葉を、身近な例に置き換えて説明してもらう

これらは活用のアイデアです。自分の文章で試すときは、質問と一緒に対象の文章も渡します。「メモを整理して」と入力するだけで、Macに保存したメモを自動で読み取るわけではありません。

## Macの中で動くAIと、サーバーで動くAI

fmは、通常はMacの中で動くAIモデルを使います。こうした動き方を「オンデバイス」と呼びます。

また、Appleの「Private Cloud Compute」という仕組みで動く、より大きなAIモデルへ切り替えることもできます。こちらはMacの外にあるサーバーで処理し、利用制限があります。[モデルの違いについての公式説明](https://developer.apple.com/videos/play/wwdc2026/334/)

「fmの処理はすべてMacの中で完結する」と覚えるのではなく、使うモデルによって処理する場所が変わる、と理解しておくとよさそうです。

なお、AppleのAIモデルを使うには、Apple Intelligenceに対応する機器が必要です。コマンドが標準搭載されていることと、AIを利用できる条件は分けて確認する必要があります。[Foundation Modelsの利用条件](https://developer.apple.com/documentation/FoundationModels)

## 作業の自動化にもつながる

fmのもう一つの用途が、繰り返す作業への組み込みです。

Appleは、ファイル名の一覧をAIに渡し、「最終版」と「下書き」に分類する例を紹介しています。その結果を使って、別の処理がファイルをバックアップ先や保管先へ振り分けます。[Appleのファイル整理デモ](https://developer.apple.com/videos/play/wwdc2026/334/)

この例では、AIが分類を担当し、ファイルをコピーしたり移動したりする部分は、あらかじめ用意した手順が担当しています。fmを起動するだけで、フォルダ全体を整理してくれるという意味ではありません。

こうした手順を作るには知識が必要ですが、日頃の作業にAIの判断を取り入れる使い道が見えてきます。

## 最初は短い文章で試してみる

fmを知る入口としては、「自分で書いた短い文章を、もっと分かりやすくしてもらう」という使い方が想像しやすいと思います。元の文章と回答を見比べれば、どこが変わったかを確認できます。

日本語でどのくらい自然に答えられるか、どのようなお願いが得意かは、実際に試して確かめたいところです。

fmは、MacのAIを文字で呼び出すための入口。まずは一つの質問から、その使い方を知ることができます。
