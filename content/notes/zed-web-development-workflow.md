# ZedでWeb制作をするときによく使う機能と操作

## 概要

普段の業務では、コードを書くときにZedというエディターを使っている。

まだすべての機能を使いこなせているわけではないので、Web制作でよく使う操作と作業の流れについてまとめる。

## プロジェクトを開く

ターミナルからプロジェクトを開く場合は、`zed`コマンドのあとにディレクトリを指定する。

```sh
zed /path/to/project
```

`zed`コマンドが使えない場合は、コマンドパレットから`cli: install cli binary`を実行する。

コマンドパレットは`Command-Shift-P`で開く。

## ファイルを探す

### ファイル名から探す

`Command-P`を押してファイル名の一部を入力すると、目的のファイルを探せる。

ファイルが多いプロジェクトでは、フォルダから順番に探すよりも早く移動できる。

### プロジェクト全体から文字列を探す

`Command-Shift-F`を押すと、プロジェクト全体から文字列を検索できる。

どのファイルを修正すればよいか分からないときは、画面に表示されている文章やクラス名を検索して探す。

### Project Panelを開く

`Command-Shift-E`を押すと、Project Panelへ移動できる。

プロジェクト全体の構成を確認したいときや、同じフォルダにあるファイルを探すときに使う。

## 複数のファイルを並べて確認する

HTMLとCSSなど、複数のファイルを見ながら作業したいときは画面を分割する。

`Command-K`を押したあとに矢印キーを押すと、矢印の方向に画面を分割できる。

次のようなファイルを並べると作業しやすい。

- HTMLとCSS
- Reactコンポーネントと型定義
- 実装ファイルと設定ファイル
- 修正するファイルと参考にするファイル

## コードを編集する

コードに問題があると、エディター上に赤や黄色でエラーや警告が表示される。

表示された場合は、ファイル名と行番号を見て内容を確認する。

ドキュメント全体を手動でフォーマットする場合は、`Command-Shift-I`を使う。

保存したときに自動で整形したい場合は、`Command-,`でSettings Editorを開き、`format_on_save`を設定する。

プロジェクトにPrettierなどの設定がある場合は、そのルールに合わせる。

## 内蔵ターミナルで動作を確認する

`Control`キーとバッククォートキーでターミナルパネルを開閉できる。

Zedにはターミナルがあるため、エディターを閉じずにコマンドを実行できる。

```sh
npm run dev
npm run build
npm run lint
```

実行できるコマンドはプロジェクトによって違うため、分からない場合は`package.json`の`scripts`を確認する。

開発サーバーを起動したあとは、ブラウザで修正したページを確認する。

- 依頼された内容が反映されているか
- PCとスマートフォンの表示が崩れていないか
- リンクやボタンが正しく動作するか
- ブラウザのConsoleにエラーが出ていないか
- 修正していない箇所へ影響していないか

## Git Panelで差分を確認する

画面下部のGitアイコンからGit Panelを開く。

Git Panelでは、現在のブランチや変更したファイルを確認できる。

作業が終わったら、変更したファイルを一つずつ開いて、意図した修正になっているか確認する。

特に次の点に注意する。

- 依頼と関係のないファイルを変更していないか
- デバッグ用のコードやコメントが残っていないか
- 不要な空白や改行だけの変更が入っていないか
- `.env`などの機密情報が含まれていないか
- 削除する予定のないコードを削除していないか

変更を取り消すときは、必要な修正まで消さないように注意する。

## 作業終了前の確認

作業が終わったら、次の順番で確認する。

1. 変更したファイルを保存する
2. ブラウザで表示と操作を確認する
3. ビルドやLintを実行する
4. Git Panelで変更ファイルと差分を確認する
5. ターミナルで`git status`を確認する
6. 問題がなければコミットとPull Requestの作業へ進む

エディターにエラーが表示されていなくても、ブラウザやビルドで問題が見つかることがある。

最後にGitの差分まで確認して、関係のない変更を含めないようにする。

## よく使うショートカット

| 操作 | macOSのショートカット |
| --- | --- |
| コマンドパレットを開く | `Command-Shift-P` |
| ファイル名から探す | `Command-P` |
| プロジェクト全体を検索する | `Command-Shift-F` |
| Project Panelへフォーカスする | `Command-Shift-E` |
| ターミナルを開閉する | `Control`キーとバッククォートキー |
| Settings Editorを開く | `Command-,` |
| ドキュメントをフォーマットする | `Command-Shift-I` |
| ペインを分割する | `Command-K`のあとに矢印キー |

操作を忘れた場合は、コマンドパレットを開いて機能名を検索する。

## まとめ

Zedでは、ファイルの検索、コードの編集、ターミナルでのコマンド実行、Gitの差分確認まで行える。

ショートカットはまだ忘れることがあるため、普段の業務で使いながら少しずつ覚えていきたい。
