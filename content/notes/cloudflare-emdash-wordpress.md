# EmDashとは？Cloudflareが発表した新しいCMSについて調べてみた

## 概要

Cloudflareが2026年4月1日に、新しいCMS「EmDash」を発表した。

EmDashは、ブログやWebサイトの記事を管理するためのオープンソースプロジェクト。Cloudflareは、EmDashを「WordPressの精神的な後継」と表現している。

ただし、WordPressを元に作られた新しいバージョンではない。WordPressが広めた、誰でもサイトを公開でき、プラグインやテーマで機能を追加できる考え方を、現在の技術で作り直そうとしている。

## WordPressと何が違うのか

WordPressはPHPで作られているが、EmDashはTypeScriptとAstroを使って作られている。

Cloudflareへ公開する場合は、Workers、D1、R2、KVなどを組み合わせて動作する。Cloudflare専用ではなく、Node.jsとSQLiteを使って自分の環境で動かすこともできる。

WordPressのプラグインやテーマをそのまま使えるわけではないため、すぐにWordPressを置き換えられるものではない。似ているのはCMSとしての考え方で、内部の仕組みは別のものになっている。

## プラグインを分けて動かす仕組み

今回の発表で特に気になったのは、プラグインの動かし方だった。

WordPressのプラグインは、WordPress本体と同じ環境で動き、データベースやファイルへアクセスできる。便利ではあるが、プラグインに問題があると、サイト全体へ影響する可能性がある。

EmDashでは、それぞれのプラグインを分離した環境で動かす。プラグインは、記事を読む、メールを送るなど、必要な権限を先に宣言する。

たとえば、記事を公開したあとにメールを送信するプラグインなら、記事を読む権限とメールを送る権限だけを許可する。関係のないデータや外部サービスには、自由にアクセスできないようにする考え方。

スマートフォンへアプリを入れるときに、カメラや位置情報の利用を確認する仕組みに少し似ている。プラグインを追加する前に、何を許可するのか分かる点は安心につながりそうだと感じた。

## EmDashでできること

EmDashには、記事の作成、下書き、予約公開、画像の管理、ユーザーごとの権限設定など、CMSでよく使う機能が用意されている。

投稿や固定ページ以外のデータも、管理画面から項目を決めて作成できる。記事の本文は、表示用のHTMLではなく、Portable Textという構造化された形式で保存される。同じ内容をWebサイト、アプリ、メールなどで使いやすくするための仕組みになっている。

ログインにはパスキーが標準で使われる。管理者、編集者、投稿者などの役割ごとに、操作できる範囲も設定できる。

## WordPressからの移行

WordPressから書き出したWXRファイルや、WordPressのAPIを使って、記事、固定ページ、画像、カテゴリなどを取り込める。

移行用のプラグインも用意されているが、既存のWordPressサイトを完全に同じ状態で移せるとは限らない。利用しているテーマ、プラグイン、独自の投稿タイプなどは、サイトごとに確認する必要がありそう。

## AIエージェントとの連携

EmDashには、AIエージェントが使うためのAgent SkillやMCPサーバーも用意されている。

AIへプラグインやテーマの作成を依頼したり、コマンドから記事やデータの構造を操作したりする使い方が考えられている。

人が管理画面から記事を書くことだけでなく、AIがサイトの作成や更新を手伝うことも、最初から想定されているところが新しいと感じた。

## コンテンツに料金を設定する機能

EmDashには「x402」という決済の仕組みも組み込まれている。

公開する内容と金額を設定し、必要な人やAIエージェントが、その都度料金を支払ってアクセスする使い方が紹介されている。

今のところ自分がすぐに使う機能ではないが、AIがWebサイトの情報を直接取得することが増えたときに、記事を作る人へどのように収益を戻すかを考えた機能として気になった。

## 現時点で分かっていること

2026年8月19日時点では、EmDashは`v0.1.0`のベータプレビュー。

ローカルでは、次のコマンドから新しいサイトを作成できる。

```sh
npm create emdash@latest
```

管理画面だけを確認できるEmDash Playgroundも公開されている。

Cloudflare上でプラグインを分離して動かすDynamic Workersは、現在は有料アカウントでのみ利用できる。無料アカウントでは、プラグイン機能を無効にして試す方法が案内されている。

まだ開発中のため、今後の仕様変更、料金、実際の運用方法など、分からないことも多い。WordPressのようにプラグインやテーマが増えていくのかも、これから確認したい。

## 発表を読んで感じたこと

WordPressは、管理画面から記事を更新でき、必要な機能をプラグインで追加できるところが便利だった。一方で、プラグインが増えると、更新や不具合、脆弱性への対応が難しくなることもある。

EmDashが、プラグインの便利さを残しながら、動かせる範囲を制限しようとしている点は面白いと思った。

また、AstroやTypeScriptを使うだけでなく、AIエージェントとの連携まで最初から考えられている。これまでのCMSを少しずつ変更するのではなく、今のWeb開発に合わせて最初から作ったCMSという印象を持った。

ただし、現時点では完成したWordPressの代わりではなく、新しいCMSの形を試している段階だと思う。実際にローカルで動かし、記事の作成やテーマの変更を試せるようになったら、操作方法についても改めてまとめたい。
