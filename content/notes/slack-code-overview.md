# Slack Codeとは？AIエージェントとの開発をチームで共有する新機能

## 概要

Slackが2026年8月20日に、AIエージェントとチームで作業するための新機能「Slack Code」を発表した。

AIエージェントへ依頼すると、作業専用の「コードチャンネル」が作られる。チームのメンバーは同じチャンネルへ参加し、会話や変更されたコードを確認しながら作業を進められる。

## Slack Codeでできること

SlackのチャンネルやDMで対応するAIエージェントをメンションすると、コードチャンネルが自動で作られる。公開または非公開を選び、必要なメンバーを追加できる。

チャンネル内では、次の内容を確認できる。

- 追加、変更されたコードの差分
- 画面を確認するためのHTMLプレビュー
- AIエージェントが作成したCanvas
- 共有されたファイルやリンク

コードの差分には行単位でコメントできる。エージェントの作業状態も表示され、必要であれば途中で止めて指示を変えられる。

## 対応するAIエージェントと利用条件

2026年8月25日時点の公式ヘルプには、次のAIエージェントが掲載されている。

- Claude
- Devin
- GitHub Copilot
- Vercel

Slack CodeはすべてのSlackプランで利用できる。ただし、使いたいAIエージェントのアプリと、サービスによっては別途有料アカウントが必要になる。

## 発表を読んで感じたこと

AIエージェントとの会話、コードの差分、プレビューが同じ場所に残るため、あとから参加する人も作業の経緯を追いやすそうだと感じた。

一方で、チャンネルに参加している全員がエージェントへ指示できると、誰の判断を優先するのか分かりにくくなる可能性もある。依頼する人、レビューする人、最終的に承認する人を決めておかないと、作業の履歴が残っても責任の所在は曖昧になりそう。

個人で使うことが多かったAIエージェントを、チームで使うための共通の作業場所として分かりやすい機能だと思う。利用できるようになったら、Pull Requestでのレビューとの使い分けを試してみたい。
