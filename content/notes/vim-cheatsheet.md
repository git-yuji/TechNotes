# よく使うVim操作のチートシート

## 概要

Vimでファイルを編集するときによく使う操作を、目的別にまとめる。

Vimのコマンドは大文字と小文字で動作が異なる。意図しない操作になった場合は、`u`で元に戻せる。

## モードを切り替える

| 操作 | 内容 |
| --- | --- |
| `i` | カーソル位置の前から入力する |
| `a` | カーソル位置の後ろから入力する |
| `I` | 行頭から入力する |
| `A` | 行末から入力する |
| `o` | 次の行に新しい行を作って入力する |
| `O` | 前の行に新しい行を作って入力する |
| `Esc` | ノーマルモードに戻る |
| `v` | 文字単位のビジュアルモードに切り替える |
| `V` | 行単位のビジュアルモードに切り替える |

コマンドが反応しないときは、まず`Esc`を押してノーマルモードに戻る。

## カーソルを移動する

| 操作 | 内容 |
| --- | --- |
| `h` | 左へ移動する |
| `j` | 下へ移動する |
| `k` | 上へ移動する |
| `l` | 右へ移動する |
| `w` | 次の単語の先頭へ移動する |
| `b` | 前の単語の先頭へ移動する |
| `e` | 単語の末尾へ移動する |
| `0` | 行の先頭へ移動する |
| `^` | 行の最初の文字へ移動する |
| `$` | 行末へ移動する |
| `gg` | ファイルの先頭へ移動する |
| `G` | ファイルの末尾へ移動する |
| `10G` | 10行目へ移動する |
| `Ctrl-d` | 半画面下へ移動する |
| `Ctrl-u` | 半画面上へ移動する |
| `%` | 対応する括弧へ移動する |

数字と移動コマンドを組み合わせると、操作を繰り返せる。たとえば`5j`で5行下へ、`3w`で3単語先へ移動する。

## 文字や行を編集する

| 操作 | 内容 |
| --- | --- |
| `x` | カーソル位置の1文字を削除する |
| `dd` | 現在の行を削除する |
| `D` | カーソル位置から行末まで削除する |
| `dw` | カーソル位置から単語の末尾まで削除する |
| `ciw` | カーソル位置の単語を削除して入力を始める |
| `cc` | 現在の行を削除して入力を始める |
| `r` | カーソル位置の1文字を置き換える |
| `u` | 直前の操作を元に戻す |
| `Ctrl-r` | 元に戻した操作をやり直す |
| `.` | 直前の変更を繰り返す |

削除コマンドにも数字を付けられる。`3dd`を実行すると、現在行から3行を削除する。

## コピー、切り取り、貼り付け

| 操作 | 内容 |
| --- | --- |
| `yy` | 現在の行をコピーする |
| `3yy` | 現在行から3行をコピーする |
| `dd` | 現在の行を切り取る |
| `p` | カーソル位置の後ろ、または次の行へ貼り付ける |
| `P` | カーソル位置の前、または前の行へ貼り付ける |

範囲をコピーする場合は、`v`または`V`で範囲を選択してから`y`を押す。選択した範囲を削除する場合は`d`を押す。

## 検索する

| 操作 | 内容 |
| --- | --- |
| `/文字列` | カーソル位置より後ろを検索する |
| `?文字列` | カーソル位置より前を検索する |
| `n` | 同じ方向の次の検索結果へ移動する |
| `N` | 反対方向の検索結果へ移動する |
| `*` | カーソル位置の単語を後ろへ検索する |
| `#` | カーソル位置の単語を前へ検索する |
| `:noh` | 検索結果のハイライトを消す |

検索文字列を入力したら、`Enter`で検索を実行する。

## 文字列を置換する

| 操作 | 内容 |
| --- | --- |
| `:s/old/new/` | 現在行の最初の`old`を`new`に置換する |
| `:s/old/new/g` | 現在行のすべての`old`を`new`に置換する |
| `:%s/old/new/g` | ファイル全体の`old`を`new`に置換する |
| `:%s/old/new/gc` | ファイル全体を確認しながら置換する |

一括置換が不安な場合は、末尾に`c`を付けて変更内容を確認しながら実行する。

## インデントを調整する

| 操作 | 内容 |
| --- | --- |
| `>>` | 現在の行のインデントを深くする |
| `<<` | 現在の行のインデントを浅くする |
| `=` | 選択範囲のインデントを整える |
| `gg=G` | ファイル全体のインデントを整える |

複数行を調整する場合は、`V`で対象行を選択してから`>`または`<`を押す。

## 保存して終了する

| 操作 | 内容 |
| --- | --- |
| `:w` | ファイルを保存する |
| `:q` | Vimを終了する |
| `:wq` | 保存して終了する |
| `ZZ` | 保存して終了する |
| `:q!` | 変更を保存せずに終了する |
| `:w ファイル名` | 別のファイル名で保存する |

`:`から始まるコマンドは、ノーマルモードで入力して`Enter`を押す。

## 困ったときの操作

| 状況 | 操作 |
| --- | --- |
| 入力モードから戻れない | `Esc`を押す |
| 間違えて編集した | `u`で元に戻す |
| 元に戻しすぎた | `Ctrl-r`でやり直す |
| 検索結果の色を消したい | `:noh`を実行する |
| 保存せずに終了したい | `:q!`を実行する |
| コマンドの使い方を調べたい | `:help コマンド名`を実行する |

たとえば、`dd`の使い方は`:help dd`、検索の使い方は`:help /`で確認できる。

## まとめ

最初からすべての操作を覚える必要はない。まずは`i`、`Esc`、`hjkl`、`dd`、`yy`、`p`、`u`、`:wq`を使い、慣れてから検索や置換などの操作を増やしていく。
